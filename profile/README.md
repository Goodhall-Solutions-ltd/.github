# Goodhall Solutions

![Goodhall Solutions](https://goodhallsolutions.co.uk/goodhall-solutions.png)

## Practical software for teams and individuals who value clarity, control and long-term stability

Goodhall Solutions designs and develops practical software for real operational and business needs.

Our first product, Fodaris, brings modern infrastructure monitoring with clean design, real alerting and operational insight, with deployment options that can evolve over time.

We are also developing Auto Invoice, a garage invoicing and business management product for small garages, MOT centres and service repair businesses.

## Public resources

Repositories in this organisation are used for public resources that support Goodhall Solutions products, including deployment templates, configuration examples, documentation resources and supporting files.

These may include resources such as Unraid Community Applications templates and Docker deployment examples.

Goodhall Solutions is not an open source software company. Commercial product source code is private unless a repository clearly states otherwise.
